# Root-level README

Create a root level README.md containing:

1. The name of the project

2. A brief description of the project and why someone would want to use it. This should be a high-level "sales pitch" or "elevator pitch". Drive excitement by describing the value.

3. Any prerequisites for running it as an end user (not as a developer of the project).

4. Usage examples and explanations as an end user (not as a developer of the project). This should be a medium-level follow-up to a "sales pitch" or "elevator pitch" where the customer has shown interest. Drive interest by showing the usefulness and the kinds of user problems the project addresses.

5. How to run the test suites, as well as how they work.

6. Any troubleshooting tips for an end user (not as a developer of the project).
