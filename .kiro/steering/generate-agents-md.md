# Generate AGENTS.md

Analyze the existing codebase, understand how it works and what it's trying to do, then create an `AGENTS.md` which provides future agents the guidance necessary to be highly effective. Include notes about hooks, agents, steering documents, and more. If it would be best to create a set of documents in order to optimize for token usage, please do that.

Include information on the technology stack, the various tools being used, and what they're being used for.
