# Add Code Comments

Update all of the source code and tests in this repository with code comments.

Specifically, I do NOT want to simply describe what the code is doing. I want to describe WHY the code is doing what it's doing. For what purpose is this function performing its function? What is the rationale?

Besides commenting at the function-level, I'd also like to add comments to particularly complex blocks of code explaining WHY we're doing the things we're doing here.

Do not prefix the comments with the word "WHY:" in order to clarify they are _why_ comments. Simply provide the explanation. Assume the reader is intelligent enough to understand that you are explaining WHY.

Always follow proper U.S. English spelling and grammar, including beginning sentences with a capital letter — unless it's a brand-name, in which case, spell the brand name correctly.
